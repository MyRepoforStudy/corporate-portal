# Вкладка «О нас»: наполнение, перевод, импорт

«О нас» — вкладка рядом с «Новости» в левой колонке главной страницы (Welcome Book банка). Редактируется в
**Админ → О нас** (HR и админ). Каждая **глава** (группа) и каждый **раздел** в ней хранятся на трёх языках (RU / KK / KO);
если для казахского или корейского текста нет, сотрудники видят русский.

> **Конфиденциальность.** Текст Welcome Book помечен как конфиденциальный, поэтому он **не хранится в репозитории**: ни в
> миграциях, ни в seed. В git лежит только код и пример с вымышленным текстом (`docs/examples/about-us.example.json`).
> Готовые файлы с реальным текстом держите вне репозитория (например, в `Documents`).

## Первая загрузка на сервере

1. `docker compose build --no-cache migrate app`
2. `docker compose run --rm migrate` — создаст таблицу `AboutSection` (миграция не затрагивает существующие данные).
3. `docker compose up -d app`
4. Админ → **О нас** → **Импорт JSON** → выбрать файл с контентом и, если в тексте есть фото, все файлы из папки с фото
   (см. «Фото» ниже).

## Формат JSON (импорт и экспорт)

```json
{
  "version": 1,
  "chapters": [
    {
      "key": "welcome",
      "title": { "ru": "Добро пожаловать", "kk": "Қош келдіңіз" },
      "body":  { "ru": "Вводный текст главы (необязательно)" },
      "sections": [
        {
          "key": "greeting",
          "isPublished": true,
          "title": { "ru": "Приветствие", "kk": "Сәлемдесу" },
          "body":  { "ru": "Текст раздела", "kk": "Бөлім мәтіні" }
        }
      ]
    }
  ]
}
```

- `key` — стабильный идентификатор (латиница в нижнем регистре, цифры, дефис), **по нему импорт находит запись**. Не меняйте его.
- Порядок глав и разделов — как в файле (для новых записей). Порядок уже существующих импорт не трогает: меняйте стрелками ↑↓ в админке.
- Импорт **ничего не удаляет** и **не стирает**: для существующей записи пишутся только те языки, которые есть в файле и не пусты.
  Новая запись требует русский заголовок.
- Можно загрузить файл только с переводами (`kk`/`ko`) — русский текст и порядок останутся как есть.

## Как добавить перевод (kk, ko)

1. Админ → О нас → **Экспорт JSON** (скачается `about-us.json` со всеми языками, включая скрытые разделы).
2. В файле заполните `kk` и/или `ko` у нужных `title` и `body` (русский не трогайте).
3. Админ → О нас → **Импорт JSON**. Либо правьте тексты вручную в окне «Изменить» (вкладки RU / KK / KO).

В списке админки у каждой записи видно, на каких языках есть текст: зелёные плашки RU / KK / KO.

## Оформление текста

Урезанный Markdown (HTML не поддерживается; ссылки — только `http(s)`, `mailto`, `tel` и пути внутри сайта):

```text
Абзацы разделяются пустой строкой.
## Подзаголовок
- пункт списка
1. пункт нумерованного списка
> важное замечание (выноска)
**жирный текст**   [ссылка](https://example.com)

| Колонка 1 | Колонка 2 |
|---|---|
| ячейка | ячейка |

![подпись](/uploads/имя-файла.jpg)
```

В окне «Изменить» есть кнопка **Предпросмотр** — тот же рендер, что увидят сотрудники.

## Фото

Фото — это обычные загрузки портала: файлы лежат в `public/uploads` (на сервере — том `portal_uploads`), **не в git**. PNG, JPEG,
WEBP или GIF, до 5 МБ на файл. Показываются только фото из `/uploads/…`: картинки с чужих сайтов портал не запрашивает (внутренняя
страница не должна выдавать читателей).

> **Доступ.** `/uploads/*` отдаётся **только вошедшим сотрудникам** (без входа — 401), а не по прямой ссылке. Это касается и
> фото новостей, и вложений.

**Из админки.** В окне «Изменить» кнопка **Вставить фото**: выбираете файл → он загружается → в текст на месте курсора вставляется
`![](/uploads/…)`. Подпись в квадратных скобках — описание для экранных читалок, её лучше заполнить. Фото вставляется в тексте
каждого языка отдельно (для KK/KO достаточно скопировать строку с фото).

**Где встанет фото** (определяется местом в тексте):

| Как написано | Как показывается |
|---|---|
| Одно фото **в начале** текста (отдельной строкой) | справа от текста, как на слайдах книги (на телефоне — над текстом) |
| Одно фото **в середине** текста (отдельной строкой) | по центру на всю ширину, высота ограничена |
| Несколько фото **в одной строке** через пробел | ряд из 2–4 картинок |
| Фото **в ячейке таблицы** | маленький портрет (список людей) |

**Импорт JSON вместе с фото.** В файле фото указывается не адресом, а именем файла:

```text
![Руководитель](about-img:chairman.jpg)
```

В окне «Импорт JSON» выберите сам JSON и (вторым полем «Фото») **все файлы из папки с фото** — можно выделить их разом. Портал
загрузит те, на которые ссылается текст, подставит адреса вместо `about-img:…` и только потом импортирует тексты. Если для имени
не выбран файл, фото из текста **убирается** (битых ссылок не остаётся), а имя показывается в отчёте: «Не выбраны файлы: …».

- Повторный импорт с фото загружает файлы **заново** (старые остаются в загрузках). Одно фото проще заменить кнопкой «Вставить фото».
- Фото из Welcome Book тоже конфиденциальны: держите папку с ними вне репозитория (как и JSON), например в `Documents`.
